Extra-Projekt: Die Wanduhr 🕒

Dein erstes ganz eigenes Anzeige-Projekt: eine große Uhr mit Datum für dein Display. Kein Internet, kein Touch — nur du, Python und die Zeit. Jeder Schritt hat eine Aufgabe, einen Tipp und eine Lösung zum Aufklappen. Erst denken, dann spicken!

🎯 Das Ziel

So soll deine Wanduhr am Ende aussehen:

  • Die Uhrzeit riesengroß in der Mitte — immer aktuell
  • Darunter das Datum auf Deutsch: „Samstag, 12. September"
  • Unten ein gelber Balken, der mit jeder Sekunde ein Stück wächst und bei der vollen Minute wieder von vorn anfängt

Alles, was du brauchst, kennst du aus Kapitel 1 bis 3: Fenster, Text anzeigen, eine Schleife. Neu ist nur ein einziger Trick: den Computer nach der Uhrzeit fragen.

1 Der blaue Hintergrund

Aufgabe: Mach ein Fenster (480 × 320) mit himmelblauem Hintergrund, das offen bleibt, bis du ESC drückst. Speichere als meine_uhr.py.

Tipp: Das ist dein Programm aus Kapitel 2, ohne die Sonne. Himmelblau war (25, 70, 130).
Lösung anzeigen 
import pygame

pygame.init()
bildschirm = pygame.display.set_mode((480, 320))

laeuft = True
while laeuft:
    for ereignis in pygame.event.get():
        if ereignis.type == pygame.QUIT:
            laeuft = False
        if ereignis.type == pygame.KEYDOWN and ereignis.key == pygame.K_ESCAPE:
            laeuft = False

    bildschirm.fill((25, 70, 130))
    pygame.display.flip()
    pygame.time.wait(200)

pygame.quit()

Fällt dir auf: fill und flip stehen diesmal in der Schleife — das Bild wird also immer wieder neu gemalt. Genau das braucht eine Uhr, denn sie ändert sich ja ständig!

2 Den Computer nach der Uhrzeit fragen

Aufgabe: Finde heraus, wie spät es ist — erstmal nur mit print, ohne pygame. Das geht mit zwei Zeilen!

Tipp: Der Baustein time kennt den Befehl time.strftime("%H:%M:%S") — er gibt dir die Uhrzeit als Text. Die komischen Zeichen sind Platzhalter: %H = Stunde, %M = Minute, %S = Sekunde.
Lösung anzeigen 
import time

print(time.strftime("%H:%M:%S"))

Starte es ein paar Mal hintereinander — die Sekunden laufen! Probier auch mal "%d.%m." für das Datum.

3 Riesengroß anzeigen

Aufgabe: Bring die Uhrzeit in dein blaues Fenster aus Schritt 1 — schön groß und ungefähr in die Mitte. Und weil alles in der Schleife passiert, aktualisiert sich deine Uhr von ganz allein!

Tipp: Text anzeigen geht mit Schrift, render und blit (kennst du aus Kapitel 3, Schritt 2). Nimm pygame.font.SysFont(None, 150) — die 150 macht sie riesig. Hol dir die Uhrzeit in der Schleife neu, direkt vor dem Malen.
Lösung anzeigen

Oben, vor der Schleife (einmal reicht):

import time
schrift_riesig = pygame.font.SysFont(None, 150)

In der Schleife, nach dem fill und vor dem flip:

    uhrzeit = time.strftime("%H:%M")
    bild = schrift_riesig.render(uhrzeit, True, (255, 255, 255))
    bildschirm.blit(bild, (100, 75))

Knobelfrage für Profis: Wie bekommst du den Text genau in die Mitte, egal wie breit er ist? bild.get_width() verrät dir seine Breite … die Rechnung dazu steht in der Musterlösung (mittig-Funktion).

4 Das Datum auf Deutsch

Aufgabe: Schreib unter die Uhrzeit das Datum wie ein echter Kalender: „Samstag, 12. September". Den Wochentag und den Monatsnamen baust du dir selbst — mit Listen!

Tipp: jetzt = time.localtime() gibt dir lauter Zahlen: jetzt.tm_wday ist der Wochentag (0 = Montag), jetzt.tm_mday der Tag, jetzt.tm_mon der Monat (1 = Januar). Mach dir zwei Listen TAGE und MONATE und hol den richtigen Namen mit TAGE[jetzt.tm_wday] heraus. Achtung beim Monat: Die Liste fängt bei 0 an, die Monate bei 1 — du brauchst also - 1!
Lösung anzeigen 
TAGE = ["Montag", "Dienstag", "Mittwoch", "Donnerstag",
        "Freitag", "Samstag", "Sonntag"]
MONATE = ["Januar", "Februar", "M\u00e4rz", "April", "Mai", "Juni", "Juli",
          "August", "September", "Oktober", "November", "Dezember"]

In der Schleife:

    jetzt = time.localtime()
    datum = (TAGE[jetzt.tm_wday] + ", " + str(jetzt.tm_mday) + ". "
             + MONATE[jetzt.tm_mon - 1])
    bild2 = schrift_mittel.render(datum, True, (220, 228, 245))
    bildschirm.blit(bild2, (110, 210))

(schrift_mittel legst du wie die riesige Schrift an, nur mit 42 statt 150.)

5 Der Sekundenbalken

Aufgabe: Male unten einen gelben Balken, der mit jeder Sekunde ein Stück breiter wird. Bei Sekunde 0 ist er weg, bei Sekunde 59 fast über den ganzen Bildschirm — und dann geht's wieder von vorn los.

Tipp: Der Bildschirm ist 480 breit, eine Minute hat 60 Sekunden — wie breit muss der Balken also pro Sekunde wachsen? Die Sekunde als Zahl bekommst du mit int(time.strftime("%S")), und ein Rechteck malen kannst du längst.
Lösung anzeigen 
    sekunde = int(time.strftime("%S"))
    pygame.draw.rect(bildschirm, (255, 210, 0), (0, 306, sekunde * 8, 14))

480 geteilt durch 60 ist 8 — pro Sekunde wächst der Balken also 8 Kästchen. Fertig ist deine Wanduhr! 🎉 Die komplette Musterlösung mit allem zusammen: code/wanduhr.py.

💻 Vom Notebook auf den Pi

Am Notebook programmiert es sich bequemer — dein Programm läuft dort genauso, nur im Fenster statt auf dem Display. So kommt es fertig auf den Pi:

  1. Speichere deine Datei am Notebook im Werkstatt-Ordner unter code/meine_uhr.py (eigener Name — die Musterlösungen bleiben unberührt!)
  2. Im Terminal am Notebook die drei Zauberwörter: 
    git add .
git commit -m "Meine Wanduhr"
git push
  3. Auf dem Pi (Terminal oder SSH): 
    cd /home/erik/erik-pi-werkstatt
git pull
python3 code/meine_uhr.py
    Aus einer SSH-Sitzung heraus: DISPLAY=:0 python3 code/meine_uhr.py — dann erscheint die Uhr auf dem Display.
🔧 Für Papa: Notebook einmalig vorbereiten
  • Thonny auf dem Notebook installieren (thonny.org) — es bringt sein eigenes Python mit
  • pygame in Thonny nachrüsten: Extras → Verwalte Pakete → „pygame" suchen → Installieren
  • Das Repo aufs Notebook clonen und Git-Zugang (Name, E-Mail, SSH-Key oder Token) einmal einrichten, damit git push ohne Nachfragen läuft

💡 Wenn sie läuft: Ausbau-Ideen

  1. Blinkender Doppelpunkt: In geraden Sekunden "15:42" anzeigen, in ungeraden "15 42" — der Trick heißt sekunde % 2
  2. Nacht-Modus: Nach 20 Uhr den Hintergrund dunkler machen — if jetzt.tm_hour hilft dir
  3. Geburtstags-Zeile: An deinem Geburtstag soll unten „🎉 Heute ist mein Tag!" stehen
  4. Wecker: Zu einer bestimmten Uhrzeit wird der ganze Bildschirm gelb
  5. Die Königsdisziplin: Bau deine Uhr klein oben in die Wetterstation ein — dann hast du zwei Projekte verschmolzen
