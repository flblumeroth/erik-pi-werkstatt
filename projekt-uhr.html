Dein erstes Projekt: Die Wanduhr 🕒

Eine echte, tickende Uhr für dein Display — und das ganze Programm hat nur 14 Zeilen. Wir bauen sie in vier kleinen Schritten. Am Ende sieht sie so aus:

📖 Bevor du startest

  • Du brauchst nur Kapitel 1 aus der Werkstatt: Thonny öffnen, tippen, grüner Pfeil.
  • In jedem Schritt siehst du dein ganzes Programm. Die gelben Zeilen sind neu — nur die tippst du dazu.
  • Ganz genau abtippen: Jede Klammer, jeder Punkt, jedes Anführungszeichen zählt. Python ist da pingelig. 😄

Öffne Thonny und speichere eine neue, leere Datei als meine_uhr.py. Los!

1 Ein blaues Fenster (6 Zeilen)

Zuerst nur ein blaues Fenster. Mehr nicht:

import pygame
import time

pygame.init()
bildschirm = pygame.display.set_mode((480, 320))
bildschirm.fill((25, 70, 130))
pygame.display.flip()
time.sleep(5)

🔍 Was passiert da?

  • import pygame / import time — wir holen zwei Werkzeugkisten: pygame kann malen, time kennt die Uhrzeit.
  • pygame.init() — weckt pygame auf. Kommt immer als Erstes.
  • bildschirm = pygame.display.set_mode((480, 320)) — macht ein Fenster: 480 breit, 320 hoch. Genau so groß wie dein Display! Es bekommt den Namen bildschirm.
  • bildschirm.fill((25, 70, 130)) — füllt alles mit Farbe. Die drei Zahlen sind Rot, Grün, Blau (0 bis 255). Das hier ist Himmelblau.
  • pygame.display.flip() — pygame malt erst heimlich auf der Rückseite. flip heißt: Umdrehen, herzeigen!
  • time.sleep(5) — 5 Sekunden warten, dann ist das Programm fertig.
✅ Grüner Pfeil! Du siehst: Ein blaues Fenster, 5 Sekunden lang.

🧪 Probier aus: Ändere die drei Farbzahlen. Was gibt (255, 0, 0)?

2 Schreib etwas hinein (3 neue Zeilen)

Text funktioniert in pygame wie ein Aufkleber: Schrift aussuchen, Text auf den Aufkleber drucken, Aufkleber ins Fenster kleben.

import pygame
import time

pygame.init()
bildschirm = pygame.display.set_mode((480, 320))
schrift = pygame.font.SysFont(None, 100)

bildschirm.fill((25, 70, 130))
bild = schrift.render("Hallo Erik", True, (255, 255, 255))
bildschirm.blit(bild, (70, 110))
pygame.display.flip()
time.sleep(5)

🔍 Die drei neuen Zeilen:

  • schrift = pygame.font.SysFont(None, 100) — sucht eine Schrift aus, Größe 100 = schön riesig.
  • bild = schrift.render("Hallo Erik", True, (255, 255, 255)) — druckt den Text auf den Aufkleber. (255, 255, 255) ist Weiß. Das True macht die Buchstaben glatt — schreib es einfach immer mit.
  • bildschirm.blit(bild, (70, 110)) — klebt den Aufkleber ins Fenster: 70 Schritte von links, 110 von oben.
✅ Du siehst: „Hallo Erik" groß und weiß im blauen Fenster.

3 Die echte Uhrzeit (1 neue Zeile)

Dein Computer weiß immer, wie spät es ist — man muss ihn nur fragen. Der Zauberspruch heißt time.strftime:

bildschirm.fill((25, 70, 130))
uhrzeit = time.strftime("%H:%M:%S")
bild = schrift.render(uhrzeit, True, (255, 255, 255))
bildschirm.blit(bild, (70, 110))

🔍 Was ist neu?

  • uhrzeit = time.strftime("%H:%M:%S") — fragt nach der Uhrzeit. Die Prozent-Zeichen sind Platzhalter: %H = Stunde, %M = Minute, %S = Sekunde. Heraus kommt ein Text wie 15:42:33, und der landet in der Schachtel uhrzeit.
  • Beim render steht jetzt uhrzeit statt "Hallo Erik" — ohne Anführungszeichen! Wir wollen ja nicht das Wort „uhrzeit" zeigen, sondern das, was in der Schachtel drinsteckt.
✅ Du siehst: Die echte Uhrzeit! Aber sie steht still wie auf einem Foto. Das reparieren wir jetzt.

4 Ticken lassen! (2 neue Zeilen — und einrücken)

Damit die Uhr tickt, muss der Computer immer wieder neu gucken und neu malen. Genau das macht while True: — es heißt: „Wiederhole für immer, was eingerückt darunter steht." Wie der „dauerhaft"-Block in MakeCode!

Hier ist das fertige Programm — alle Mal-Zeilen sind jetzt eingerückt in die Schleife gewandert, und aus sleep(5) wurde sleep(0.2):

import pygame
import time

pygame.init()
bildschirm = pygame.display.set_mode((480, 320))
schrift = pygame.font.SysFont(None, 100)

while True:
    pygame.event.pump()
    uhrzeit = time.strftime("%H:%M:%S")
    bildschirm.fill((25, 70, 130))
    bild = schrift.render(uhrzeit, True, (255, 255, 255))
    bildschirm.blit(bild, (70, 110))
    pygame.display.flip()
    time.sleep(0.2)

🔍 Was ist neu?

  • while True: — die Endlos-Schleife. Alles Eingerückte wiederholt sich: Uhrzeit fragen → blau füllen → Aufkleber drucken → kleben → herzeigen → 0,2 Sekunden Pause → von vorn. Deshalb ist die Uhr immer aktuell!
  • pygame.event.pump() — sagt dem Fenster jede Runde kurz Bescheid, damit es nicht einschläft. Einfach mit reinschreiben.
  • Die Einrückung (4 Leerzeichen) sagt Python, was zur Schleife gehört — Thonny rückt nach dem Doppelpunkt automatisch ein.
  • Stoppen: mit dem roten Stopp-Knopf in Thonny. („Für immer" gilt nur, bis du auf Stopp drückst. 😄)
🏆 Du siehst: Die Sekunden ticken — deine Uhr LEBT! Das war dein erstes eigenes Python-Projekt. 🎉
Wenn Python meckert: Die Fehlermeldung nennt dir die Zeile! SyntaxError = meist Doppelpunkt oder Anführungszeichen vergessen. IndentationError = Einrückung stimmt nicht, vergleiche genau mit oben. Zur Not: Musterlösung code/wanduhr.py daneben halten und den Unterschied suchen — echte Detektivarbeit!

★ Bonus 1: Das Datum (3 neue Zeilen)

strftime kennt noch mehr Platzhalter: %d = Tag, %m = Monat, %Y = Jahr. Eine kleinere zweite Schrift, ein zweiter Aufkleber — fertig. Oben bei der Schrift:

schrift = pygame.font.SysFont(None, 100)
schrift_klein = pygame.font.SysFont(None, 44)

Und in der Schleife, unter der blit-Zeile:

    bildschirm.blit(bild, (70, 110))
    datum = schrift_klein.render(time.strftime("%d.%m.%Y"), True, (220, 228, 245))
    bildschirm.blit(datum, (150, 200))
✅ Unter der Uhr steht jetzt das Datum, z. B. 12.09.2026.

★ Bonus 2: Der Sekunden-Balken (2 neue Zeilen)

Ein gelber Balken unten, der mit jeder Sekunde wächst — und bei der neuen Minute wieder bei null anfängt. In die Schleife, vor das flip:

    sekunde = int(time.strftime("%S"))
    pygame.draw.rect(bildschirm, (255, 210, 0), (0, 306, sekunde * 8, 14))
    pygame.display.flip()

🔍 Die zwei Zeilen:

  • int(...) — die Sekunde kommt als Text („07"), aber rechnen kann man nur mit Zahlen. int verwandelt Text in eine Zahl.
  • pygame.draw.rect(...) — malt ein Rechteck: bei x=0, y=306 (fast ganz unten), Breite sekunde * 8, Höhe 14. Warum mal 8? Der Bildschirm ist 480 breit, die Minute hat 60 Sekunden — und 480 : 60 = 8. 🧠
🏆 Uhrzeit, Datum, wachsender Balken — das komplette Programm steht in code/wanduhr.py.
